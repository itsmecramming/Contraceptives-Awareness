# Smart Choices, Safe Futures

A modern, masculine medical-themed web interface for the Contraceptive Awareness platform.

## 🚀 Live Demo
Check out the live deployment here: [https://contraceptives-awareness.vercel.app/](https://contraceptives-awareness.vercel.app/)

## 🛠 Features
- **Dual-Theme Support:** Toggle between Light and Dark modes.
- **Interactive Infographics:** High-level visual protocols with Lightbox functionality.
- **Masculine Medical Aesthetic:** Clinical professionalism combined with a strong tactical edge.
- **Responsive Design:** Optimized for various screen sizes.

## 📁 Project Structure
- `index.html`: Home page with hero section and visual protocol.
- `content.html`: Comprehensive knowledge base with interactive accordions and tabs.
- `authors.html`: Meet the architects behind the platform.
- `css/`: Styling for global, content, and authors pages.
- `js/`: Main interaction scripts including theme switching and lightbox logic.
- `assets/`: Logos, infographics, and theme-specific assets.
